# Задача: Массовая загрузка постов в SMM-календарь

**Статус:** `new`
**Номер:** 033
**Автор:** Лена
**Дата создания:** 2026-05-12
**Тип:** `smm`

---

## Контекст

Сейчас в контент-календарь записи можно заносить только по одной через AI-генерацию плана или ручное редактирование поста. Это неудобно когда хочется спланировать сразу полгода вперёд: 50+ постов руками — нереально.

Нужно дать поле для ввода массива записей и кнопку «Загрузить», чтобы все записи распарсились по одной, попали в БД как обычные посты со статусом «черновик» и привязкой к рубрике/формату.

---

## Спек

### Что нужно сделать

1. На странице `/smm/` добавить блок «Загрузить календарь»:
   - Большое текстовое поле (textarea, не меньше 10 строк) — ввод массива.
   - Кнопка «Загрузить» — парсит и создаёт посты.
   - Кнопка «Сохранить черновик» — сохраняет текст из поля без обработки (чтобы можно было вернуться позже).
   - Краткая шпаргалка по формату прямо рядом с полем.

2. После загрузки:
   - Текст в поле **не очищается** — Лена сама может его удалить или продолжить редактировать.
   - Сверху появляется отчёт: «Создано N · Дублей пропущено M · Ошибок K» + детальный список (что создалось, что пропустилось, что не распарсилось).
   - Черновик сохраняется автоматически (на случай перезагрузки страницы).

3. Дедупликация:
   - Дубль = полное совпадение по полям `(publish_date, platform_format, rubric, topic)`.
   - Дубли внутри загрузки и с уже существующими постами в БД пропускаются с сообщением.

### Формат данных

**Базовый формат (по умолчанию)** — построчно через `|`:

```
2026-06-01 | dzen/long | family_stories | Как сохранить семейные традиции
2026-06-03 | vk/short | children | Игры для бабушек и внуков | Заголовок здесь | family memoir illustration | true
# строки, начинающиеся с # — комментарии (игнорируются)
2026-06-05 | telegram/post | reviews | История клиентки Марии: книга для мамы
```

Поля (по порядку):
1. `дата` — `ГГГГ-ММ-ДД` (также принимается `ДД.ММ.ГГГГ`)
2. `площадка/формат` — slug из настроек либо `название_площадки/название_формата`
3. `рубрика` — slug либо название рубрики
4. `тема` — произвольный текст
5. `заголовок` (опционально) — если уже придумали `article_title`
6. `промпт_картинки` (опционально)
7. `диалог` (опционально) — `true`/`false` для включения «инициировать диалог»

**TSV-формат** (для копирования из Excel/Google Sheets) — те же колонки, но через TAB. Первая строка с заголовками распознаётся и пропускается.

**JSON-формат** — массив объектов:

```json
[
  {"date": "2026-06-01", "platform_format": "dzen/long", "rubric": "family_stories", "topic": "..."},
  {"date": "2026-06-03", "platform_format": "vk/short", "rubric": "children", "topic": "...", "title": "...", "initiate_dialog": true}
]
```

Парсер автоматически определяет формат: `[` → JSON, TAB → TSV, иначе → pipe.

### Как должно выглядеть в итоге

1. Открываю `/smm/`.
2. Вижу блок «📥 Загрузить календарь» с большим полем.
3. Вставляю в поле массив (50–100 строк на полгода).
4. Нажимаю «Загрузить».
5. Вижу зелёный баннер: «Создано 47 · Дублей пропущено 2 · Ошибок 1» + раскрывающийся список деталей.
6. Текст в поле остался — могу нажать «Загрузить» повторно (все будут отмечены как дубли) или поправить и догрузить.
7. После перезагрузки страницы — текст подгрузился из черновика.

### Как проверить

1. Создать в `/smm/settings`:
   - Рубрика «family_stories»
   - Площадка/формат «Дзен / Лонгрид» (slug `dzen_lonjrid`)
2. На `/smm/` вставить в поле:
   ```
   2026-06-01 | dzen_lonjrid | family_stories | Тест-тема 1
   2026-06-02 | dzen/Лонгрид | family_stories | Тест-тема 2
   2026-06-01 | dzen_lonjrid | family_stories | Тест-тема 1
   ```
3. Нажать «Загрузить».
4. Ожидаемо: создано 2 поста, 1 дубль пропущен.
5. Повторить — все 3 идут в дубли.
6. Перезагрузить страницу — текст в поле остался.

## Реализация

> Заполняет агент.

**Что сделано:**

1. Добавлен модуль `smm/calendar_import.py` — чистые функции парсинга и импорта (без прямых обращений к БД, всё через коллбэки → удобно для тестов).
2. Расширен `smm/db_smm.py`: добавлены вспомогательные функции `get_existing_post_signatures()` для дедупликации и `get_active_pformats_full()` для резолва slug-ов.
3. Добавлены роуты в `admin/blueprints/smm.py`:
   - `POST /smm/calendar/import` — парсит textarea, создаёт посты, возвращает отчёт.
   - `POST /smm/calendar/draft` — сохраняет текст из textarea как черновик (без импорта).
4. Шаблон `admin/templates/smm/index.html`: новый блок «📥 Загрузить календарь» с textarea, кнопками, шпаргалкой по формату и блоком отчёта об импорте.
5. Контроллер `index` подгружает существующий черновик из таблицы `prompts` (роль `smm_calendar_import_draft`) и передаёт в шаблон.
6. Тесты: `tests/test_smm_calendar_import.py` — парсер, резолвер, импортёр, дедупликация, ошибки.
