## Спек

### Что нужно изменить

**`normalize_topo_via_gazeteer` в `pipeline_utils.py`:**

Для каждого entry в gazeteer (например `"Сапоново": "Сафроново"`):
1. Сгенерировать **set вариантов** для match'а:
   - Именительный: `Сапоново` → match
   - Родительный: `Сапонова` (отбрасывая «о», добавляя «а»)
   - Дательный: `Сапонову` (отбрасывая «о», добавляя «у»)
   - Творительный: `Сапоновом` (добавляя «м»)
   - Предложный: `Сапонове` (отбрасывая «о», добавляя «е»)

2. Для replacement — генерировать соответствующую форму **canonical**:
   - «Сапонова» → «Сафронова» (родительный канонический)
   - «Сапонову» → «Сафронову»
   - и т.д.

**Generic morphology helper:**

```python
def generate_russian_case_forms(word: str) -> dict[str, str]:
    """Грубая морфология для русских топонимов на -о/-а/-ы.
    
    Возвращает:
      {"nom": "Сапоново", "gen": "Сапонова", "dat": "Сапонову",
       "instr": "Сапоновом", "prep": "Сапонове"}
    """
    if word.endswith('о'):
        stem = word[:-1]
        return {
            'nom': word,
            'gen': stem + 'а',
            'dat': stem + 'у',
            'instr': stem + 'ом',
            'prep': stem + 'е',
        }
    elif word.endswith('а'):
        stem = word[:-1]
        return {
            'nom': word,
            'gen': stem + 'ы',
            'dat': stem + 'е',
            'instr': stem + 'ой',
            'prep': stem + 'е',
        }
    # other endings — keep as is, only nominative
    return {'nom': word}
```

При normalize — для каждой канонической пары:
- Найти все формы wrong word (5 падежей)
- Заменить на соответствующие формы canonical word
