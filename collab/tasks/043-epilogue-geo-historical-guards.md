## Контекст (кратко)

Из feedback Никиты по v56:

**Epilogue пластиковый (Класс 6):**
- «Валентина Ивановна была человеком своего времени»
- «история обычной советской женщины, которая прошла через испытания XX века и сохранила достоинство»
- «путь от сироты из украинского села до уважаемой медсестры в подмосковном городе»

**Geo misattribution (Класс 7):**
- Химинститут — «подмосковный город». В реальности: посёлок городского типа на окраине Калинина (= Тверь, **не Подмосковье**). GW сделал региональное допущение которого нет в fact_map.

**`historical_notes` underutilization (Класс 9):**
- Сводка отчёта: «Historical notes: 2». В тексте ch_02 inline 5 справок в формате `***...***`. То есть GW кладёт справки **inline**, а отдельное поле `historical_notes` использует мало → на вёрстке Stage 4 справки не рендерятся как отдельный визуальный блок.

Все 3 класса универсальны.

## Definition of Done

- ✅ Скрипт `validate_epilogue_no_platitudes(book, stop_phrases)` в `pipeline_utils.py`:
  - Stop-list расширить из gate1 checklist + новые («человек своего времени», «история обычной советской женщины», «путь от X до Y», «прошла через испытания XX века», «сохранила достоинство»)
  - Применяется к `epilogue.paragraphs[].text`
  - На FAIL — flag + список найденных фраз; **не auto-replace** (стиль решается GW)
- ✅ Скрипт `validate_geo_claims(book, fact_map, geo_dict)`:
  - Geo_dict — мапа регион-прилагательное → канонический регион (`подмосковный → Московская область`, `сибирский → Сибирь`, `уральский → Урал`, ...)
  - Grep на регион-прилагательные в book → проверка что место в fact_map.locations принадлежит этому региону
  - На FAIL — flag с pointer (chapter_id, location, claim)
- ✅ Скрипт `reclassify_historical_notes(book)`:
  - Найти inline `***...***` блоки в paragraphs[].text
  - Перенести в `historical_notes` field с year_reference (если есть в тексте)
  - Из paragraph.text удалить inline
  - ИЛИ — реверс (если field имеет содержимое, продублировать inline) — выбрать политику на основе вёрстки Stage 4
- ✅ Промпт GW (минорный патч): расширить стоп-фразы для epilogue + явный запрет `***...***` inline блоков (всё через field)
- ✅ Tests + integration на v56 артефактах
