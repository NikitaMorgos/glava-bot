`scoped_chapter_ids` — главы где проверка обязательна (epilogue). `extra_general_scope` — где warning, не error (некоторые фразы допустимы в нарративе).

**2. Скрипт `validate_epilogue_stop_phrases(book, stop_list) -> report`** в `pipeline_utils.py`:

Алгоритм:
1. Для каждой главы из `stop_list.scoped_chapter_ids`:
   - Извлечь весь текст (content + paragraphs)
   - Для каждой stop-phrase: case-insensitive substring search
   - Если найдено → `{phrase, chapter_id, snippet, severity: "error"}` 
2. Для `extra_general_scope`:
   - То же, но `severity: "warning"`
3. Возвращает `{issues: [...], errors_count: N, warnings_count: M}`

**3. Скрипт `validate_awkward_formulation(book) -> report`** в `pipeline_utils.py` (**Класс 11**):

Алгоритм:
1. Regex pattern «не любил советы по X или Y» в narrative chapters: `\bне любил\s+\w+\s+(по|про|о|об|с|насчёт)\s+\S+\s+(или|и|,)\s+\S+`
2. Альтернативно: `\bне нравил.*когда\s+\w+\s+(давал|просил)\s+\w+\s+(по|про|о)\s+\S+\s+(или|и)\s+\S+`
3. На match → flag `type="example_instead_of_generalization"` с suggestion (грубо: «убрать конкретику X/Y, написать «не любил советов в принципе; например, по X или Y»)
4. Эвристика, не точный матч — ожидаются false positives. Severity: warning.

**4. Функция `enforce_paspart_format(book) -> book`** в `pipeline_utils.py`:

Алгоритм:
1. Найти в `bio_data.family[]` все значения / notes / content
2. Replace patterns:
   - `\bр\.\s*(\d{4})` → `родился? в \1 году` (детерминировать рода по родственнику: сын/брат/отец/муж/дед/внук → «родился»; дочь/мать/сестра/жена/бабушка/внучка → «родилась»)
   - `\bум\.\s*(\d{4})` → `умер? в \1 году` (с тем же родовым правилом)
3. В ch_01.content (markdown паспортичка) — то же
4. Idempotent
