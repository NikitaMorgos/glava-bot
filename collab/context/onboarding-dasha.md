# Онбординг агента Даши

> Для Даши — всё что нужно, чтобы твой разработчик заработал.

---

## Что изменилось

Раньше: ты пишешь задачу → ждёшь пока Никита реализует.
Теперь: ты пишешь задачу → твой агент реализует сам → в репо появляется готовый результат.

Никита остаётся в цепочке только для задач с высоким риском. Остальное — твой агент закрывает автономно.

## Установка (один раз)

### 1. Инструмент — Cursor или Claude Code (на выбор)

**Cursor:** https://cursor.com — скачай и установи как обычное приложение.

**Claude Code** (если уже пользуешься Claude): терминальный инструмент от Anthropic.
```bash
npm install -g @anthropic-ai/claude-code
```
Требует Node.js и ключ Anthropic API — попроси у Никиты если нет.

Оба варианта работают одинаково с точки зрения задач и git.

### 2. Доступ к репозиторию

Попроси Никиту добавить твой GitHub-аккаунт как collaborator в репо `glava-bot`.

Затем склонируй репо:

```bash
git clone https://github.com/NikitaMorgos/glava-bot.git
cd glava-bot
```

Или через Cursor: **File → Open Folder** → выбери папку `glava-bot`.

### 3. Настрой git (один раз)

```bash
git config user.name "Dasha"
git config user.email "твой@email.com"
```

## Как работать с задачами

### Шаг 1 — Создай задачу

Создай новый файл в `collab/tasks/` по шаблону `_template.md`.

Назови файл: `NNN-короткое-название.md` (номер следующий по порядку).

Заполни обязательно:
- **Автор:** Даша
- **Контекст** — почему нужна задача
- **Спек** — что конкретно сделать, какой результат ожидается, как проверить
- **Ограничения** — что нельзя трогать

### Шаг 2 — Открой чат и скажи агенту кто ты

**В Cursor** нажми `Ctrl+L`. В начале сессии напиши:
```
Ты агент Даши. Прочитай .cursor/rules/dasha-agent.mdc — это твои правила.
```

**В Claude Code** запусти в терминале `claude` и напиши то же самое.

После этого дай задачу:

```
Возьми задачу collab/tasks/NNN-название.md и реализуй её.
```

Агент:
1. Прочитает задачу
2. Проведёт Dev Review (поднимет флаги если есть вопросы)
3. Если флагов нет — сразу начнёт реализацию
4. Прогонит тесты
5. Закоммитит и смёрджит в dev

### Шаг 3 — Если агент поднял [PRODUCT] флаг

Агент напишет в чат что нашёл продуктовый вопрос. Ответь на него — и он продолжит.

### Шаг 4 — Проверь результат (если хочешь)

Агент поставит статус `done` или `dasha-review` в файле задачи.

Если `dasha-review` — он ждёт твоей проверки перед закрытием.

## Что твой агент умеет делать сам

- Редактировать промпты (`prompts/*.md`)
- Менять сценарии и тексты бота (`main.py`)
- Добавлять/менять CCO-скрипты (`cco/`)
- Создавать новые агенты в pipeline
- Писать тесты для своих изменений

## Что требует участия Никиты

- Изменение формата данных между агентами (JSON-контракты)
- Задачи, касающиеся оплаты
- Что-то в базе данных
- Кросс-доменные задачи (затрагивает и SMM, и pipeline)

Агент сам создаст PR и напишет тебе — ты просто пересылаешь Никите.

---

## Если что-то пошло не так

1. Напиши в чате Cursor: «стоп, объясни что происходит»
2. Агент опишет где застрял
3. Если непонятно — напиши Никите с описанием и скриншотом чата

## Быстрая шпаргалка

| Хочу | Что делать |
|------|-----------|
| Поменять текст промпта | Задача типа `промпт` в collab/tasks/ |
| Изменить сценарий бота | Задача типа `сценарий-бота` |
| Добавить нового агента в pipeline | Задача типа `новый-агент` |
| Посмотреть что сделал агент | Открыть файл задачи, секция «Реализация» |
| Отменить изменения | Напиши агенту «откати всё» |
