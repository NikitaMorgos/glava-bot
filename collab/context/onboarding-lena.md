# Онбординг агента Лены

> Для Лены — всё что нужно, чтобы твой разработчик заработал.

---

## Что это такое

У тебя теперь есть собственный AI-разработчик внутри Cursor. Ты пишешь что нужно сделать — он делает: меняет лендинг, готовит SMM-контент, настраивает расписание публикаций. Без ожидания в очереди к Никите.

Никита остаётся в картинке только для технически сложных задач. Всё маркетинговое — твой агент закрывает сам.

---

## Установка (один раз)

### 1. Инструмент — Cursor или Claude Code (на выбор)

**Cursor:** https://cursor.com — скачай и установи как обычное приложение.

**Claude Code** (если уже пользуешься Claude): терминальный инструмент от Anthropic.
```bash
npm install -g @anthropic-ai/claude-code
```
Требует Node.js и ключ Anthropic API — попроси у Никиты если нет.

Оба варианта работают одинаково с точки зрения задач и git.

### 2. Доступ к репозиторию

Попроси Никиту добавить твой GitHub-аккаунт в репо `glava-bot` как collaborator.

Затем склонируй репо:

```bash
git clone https://github.com/NikitaMorgos/glava-bot.git
cd glava-bot
```

Или через Cursor: **File → Open Folder** → выбери папку `glava-bot`.

### 3. Настрой git (один раз)

```bash
git config user.name "Lena"
git config user.email "твой@email.com"
```

## Как ставить задачи агенту

### Шаг 1 — Создай файл задачи

В папке `collab/tasks/` создай новый файл `NNN-название.md` (возьми следующий номер).

Можно скопировать `collab/tasks/_template_lena.md` как основу.

Заполни:
- **Автор:** Лена
- **Контекст** — зачем это нужно
- **Спек** — что конкретно сделать и как должно выглядеть
- **Как проверить** — как ты поймёшь что всё сделано правильно

Не нужно заполнять технические разделы (Dev Review, Реализация) — это делает агент.

### Шаг 2 — Скажи агенту кто ты

**В Cursor** нажми `Ctrl+L`. В начале каждой сессии напиши:
```
Ты агент Лены. Прочитай .cursor/rules/lena-agent.mdc — это твои правила.
```

**В Claude Code** запусти `claude` в терминале и напиши то же самое.

Затем дай задачу:

```
Возьми задачу collab/tasks/NNN-название.md и реализуй её.
```

Агент сделает всё остальное: поймёт что нужно, внесёт изменения, закоммитит.

### Шаг 3 — Проверь результат

Агент напишет в чат когда закончит. Можешь попросить показать что изменилось:

```
Покажи что ты изменил
```

Если что-то не так — напиши что именно не устраивает, агент поправит.

## Что твой агент умеет делать сам

| Задача | Где это живёт |
|--------|--------------|
| Тексты и контент лендинга | `landing/` |
| Шаблоны SMM-постов | `admin/templates/smm/` |
| Расписание публикаций | `smm/scheduler.py` |
| Настройки SMM-панели | `admin/templates/smm/settings.html` |
| Визуальные изменения в SMM-панели | `admin/templates/smm/*.html` |

## Что требует участия Никиты

- Подключение нового соцсетевого канала
- Добавление нового раздела в базу данных
- Интеграция с новым внешним сервисом
- Задача касается бота или pipeline

Агент сам создаст PR и скажет тебе — ты просто пересылаешь Никите.

## Примеры задач (скопируй и адаптируй)

**Пример 1 — Контент лендинга:**
```
Контекст: хотим обновить блок "Как это работает" на главной странице.
Спек: заменить текст в трёх шагах на более эмоциональный. 
  Шаг 1: "Расскажите истории" → "Поделитесь воспоминаниями голосом"
  Шаг 2: "Мы обработаем" → "ИИ превратит их в живой текст"  
  Шаг 3: "Получите книгу" → "Получите семейную книгу-биографию"
Как проверить: открыть лендинг, увидеть новые тексты.
```

**Пример 2 — SMM:**
```
Контекст: хотим добавить новый шаблон поста для Instagram — анонс новой функции.
Спек: шаблон с заголовком, коротким текстом (до 150 символов), CTA-кнопкой.
  Стиль: тёплый, личный, без формализма.
Как проверить: шаблон появился в SMM-панели и его можно выбрать при создании поста.
```

## Если что-то пошло не так

1. Напиши в чате: «стоп, что происходит?» — агент объяснит
2. Если непонятно — напиши Никите с описанием и скриншотом чата
3. Откатить изменения: напиши агенту «откати всё что ты сделал»

---

## Быстрый старт прямо сейчас

1. Установи Cursor → попроси Никиту дать доступ к репо
2. Открой репо в Cursor
3. Создай первую маленькую задачу в `collab/tasks/`
4. Напиши в чат: «Возьми задачу collab/tasks/XXX.md и реализуй»
5. Смотри как агент работает
