# Gate-1 продуктовый чек-лист — текст до вёрстки

**Назначение:** Прохождение Ворот 1 (текст готов до вёрстки) на каждом прогоне Каракулиной (и далее на других субъектах). Используется Никитой+Дашей при чтении `karakulina_v<N>_text_FULL.md`, сгенерированного `scripts/build_gate1_full_text.py`.

**Версия:** v1 (черновик, 2026-05-08, Опус). Даша дополняет/правит — это **продактовый документ**, не инженерный.

**Связано:** [product-goal.md](product-goal.md), [task 009 acceptance gates](../tasks/009-acceptance-gates-protocol.md), [karakulina-versions-metrics.md](karakulina-versions-metrics.md)

---

## Как пользоваться

1. После прогона v<N>: Курсор запускает `python scripts/build_gate1_full_text.py --book-final <path> --fact-map <path> --output <path>`
2. Полученный `karakulina_v<N>_text_FULL.md` Никита/Даша читают **в один проход** (это специально один файл).
3. Открыть этот чек-лист параллельно. Каждый пункт — отметить ✅ / ⚠️ / ❌.
4. Решение:
   - **Все ✅** → Ворота 1 пройдены, идём к Stage 4 / следующему этапу
   - **>3 ❌ разных категорий** → срабатывает правило ретро (см. `dev-review-protocol`), откат на ближайший RP, пересборка плана
   - **1-3 ❌** → точечные промпт-фиксы (НЕ новая волна защит), следующий прогон v<N+1>

## 4. Стилистика — отсутствие пластиковых обобщений

GW v2.17 ЗАПРЕТ 8: первый абзац каждой главы/подсекции содержит ≥1 конкретный факт.

**Стоп-фразы (если есть в MD — ❌):**
- «X была человеком ярких поступков»
- «X отличалась удивительной стойкостью»
- «За внешней строгостью скрывались...»
- «Жизнь X вместила в себя множество испытаний»
- «X была человеком своего времени» (в начале главы — допустимо в epilogue)

**Стоп-фразы из GW v2.14 (СТОП-ФРАЗЫ):**
- «жизнь налаживалась», «жизнь устраивалась»
- «настал новый этап», «всё изменилось»
- «это стало поворотным моментом»
- «болезненное событие/решение» (если рассказчик не говорил)
- «тяжёлое испытание»
- «интересно, что...», «примечательно, что...», «стоит отметить, что...»
- «именно поэтому...», «не случайно, что...»

**Тест на пластиковость каждого первого абзаца главы:**
> Можно ли поставить это первое предложение в начало книги про ЛЮБОГО человека?

Если **да** — это пластик, ❌. Если **нет** (есть имя/год/предмет/место) — ✅.

## 6. Cross-chapter dedup (один эпизод — одна глава)

Каждый эпизод из `fact_map.timeline` подробно рассказан в **одной** главе. В других главах — только короткие ссылки (1 предложение), без повторного дословного рассказа.

| Критерий | Цель | Как проверить | Статус |
|---|---|---|---|
| Огурцы Молдавия — только ch_02 (или ch_04, но не оба) | не разворачивается дважды | grep `чемодан` — count должен быть 1-2 (упоминание + контекст) | |
| Документы вокзала — только в ch_02 | то же | grep `вокзал` | |
| Награды — только в ch_01 paspport, не в ch_02 | bio_data.awards единственное место | grep по конкретным наградам | |
| Семья (родственники) — портреты в ch_01 family, истории в ch_02 | разные глубины раскрытия | визуально | |

**Если эпизод раскрыт дословно в 2+ главах** — это регрессия #4 (cross-chapter дубль). На v36 закрыта в волне 1.2.
