## Как пользоваться

1. При прогоне Каракулины — `Completeness Auditor` использует этот список как pin-list. Если эпизод/персона из него **отсутствует** в `fact_map.timeline` или `fact_map.persons` — флаг `was_in_pin_list: true`.

2. При прохождении `gate1_product_checklist.md` категории 3 (Известные эпизоды) — Даша/Никита грепают по `karakulina_v<N>_text_FULL.md`:
   - Эпизод найден (≥1 маркер) → ✅
   - Эпизод не найден → ❌
3. При >3 ❌ → срабатывает RETRO (новая пересборка плана).

4. **Источник правды для других субъектов** — аналогичный pin-list в `collab/context/known_episodes_<subject>.md` (будет создан для Корольковой/Дмитриева).
