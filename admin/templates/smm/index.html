Как работает SMM-редакция v2
Полная цепочка
1
🔍 Скаут генерирует темы

Для каждой темы указывает рубрику и площадку/формат. Следит за уникальностью — не повторяет темы из последних планов.

system: Скаут Стратегия + все Площ./Форм. + все Рубрики
2
✍️ Журналист пишет статью

По рубрике + формату выбирается нужный журналист. Вставляет маркер [ИЛЛЮСТРАЦИЯ] — место для картинки внутри текста.

system: промпт журналиста + промпт рубрики + описание формата

💬 На карточке поста можно включить «Инициировать диалог» — тогда журналист добавит призыв к читателям в конце.

3
🎨 Иллюстратор → 2 изображения

Генерирует обложку + иллюстрацию внутри текста (для места маркера). Стиль берёт из промпта рубрики — опиши там, нужно ли реалистичное фото или иллюстрация.

system: Иллюстратор + промпт рубрики + требования площадки
4
📋 Выпускающий редактор → решение

Оценивает текст + визуал как единый материал. Проверяет соответствие целям рубрики — видит её промпт.

system: Редактор текст + обложка + промпт рубрики
5
👁 Лена одобряет → 📅 дата → 🚀 публикация

Назначь дату публикации, одобри пост — и он уйдёт на площадку автоматически.

Настройки: Площадки/Форматы · Рубрики · Журналисты · Служебные роли
💡 Рубрики: описывай типы изображений прямо в промпте рубрики — Иллюстратор их увидит.
💡 Рубрики: если в одну рубрику пишут разные журналисты на разные темы — разбей её на несколько узких.
